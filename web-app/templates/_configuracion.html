Configuración

Para que registremos automáticamente tus gastos, configura tu correo personal para que reenvíe las notificaciones de tu banco a tu dirección de reenvío de neto. Solo tienes que hacerlo una vez.

Tu dirección de reenvío
{% if email_forward %}

Esta es la dirección a la que tu banco debe reenviar las notificaciones. Cópiala para pegarla en la regla de tu proveedor de correo.

{{ email_forward }}
{% else %}
Aún no tienes una dirección de reenvío asignada. Contacta al administrador para activarla.
{% endif %}
Crea la regla de reenvío
Reenvío y POP/IMAP Filtros y direcciones bloqueadas
  1. Abre Configuración → Reenvío y correo POP/IMAP y haz clic en «Agregar una dirección de reenvío». Pega esta dirección y confirma el código que enviaremos a esa bandeja: {% if email_forward %}{{ copyrow('Reenviar a', email_forward, 'gm-fwd') }}{% endif %}
  2. Ve a Configuración → Filtros y direcciones bloqueadas → «Crear un filtro nuevo».
  3. Pega este bloque en el campo «De» y haz clic en «Crear filtro»: {{ copyrow('Campo «De»', senders_all, 'gm-de') }}
  4. Marca «Reenviarlo a», elige tu dirección de reenvío y guarda el filtro.
Reglas de Outlook Reenvío de Outlook
  1. Abre Configuración → Correo → Reglas y haz clic en «Agregar nueva regla». Ponle un nombre (por ejemplo «Reenvío neto»).
  2. En «Agregar una condición» elige «De» y agrega cada una de estas direcciones por separado. Outlook no usa OR: cuando agregas varias direcciones a la condición «De», las combina automáticamente (coincide si el correo viene de cualquiera de ellas). Agrégalas una por una desde esta lista: {{ copyrow('Direcciones «De»', senders_list, 'ol-de') }}
  3. En «Agregar una acción» elige «Reenviar a» y pega tu dirección de reenvío: {% if email_forward %}{{ copyrow('Reenviar a', email_forward, 'ol-fwd') }}{% endif %}
  4. Guarda la regla.
Ajustes de Yahoo Mail
  1. Para el reenvío automático, ve a Ajustes → Más ajustes → Buzones → Reenvío, agrega esta dirección y confirma el código que enviaremos a esa bandeja: {% if email_forward %}{{ copyrow('Reenviar a', email_forward, 'ya-fwd') }}{% endif %}
  2. Ve a Ajustes → Más ajustes → Filtros → «Agregar nuevos filtros».
  3. En «Remitente» selecciona «contiene» y pega este bloque: {{ copyrow('Remitente contiene', senders_all, 'ya-de') }}
  4. Guarda los cambios.

El reenvío automático de Yahoo puede requerir Yahoo Mail Plus. Si el filtro no acepta el bloque completo, crea un filtro por cada dirección del bloque.

iCloud Mail
  1. Abre iCloud Mail en el navegador y haz clic en el icono de engranaje → «Reglas» → «Agregar una regla».
  2. En «Si un mensaje es de» pega este bloque: {{ copyrow('Si es de', senders_all, 'ic-de') }}
  3. En «Entonces» elige «Reenviar a» y pega tu dirección de reenvío: {% if email_forward %}{{ copyrow('Reenviar a', email_forward, 'ic-fwd') }}{% endif %}
  4. Guarda la regla.

Si iCloud solo permite una dirección por regla, crea una regla por cada dirección del bloque.

  1. Entra a los ajustes de tu correo y busca la sección de «Filtros», «Reglas» o «Reenvío».
  2. Crea una regla cuya condición sea que el remitente (De) coincida con este bloque: {{ copyrow('Remitente (De)', senders_all, 'ot-de') }}
  3. Define la acción «Reenviar a» hacia tu dirección de reenvío: {% if email_forward %}{{ copyrow('Reenviar a', email_forward, 'ot-fwd') }}{% endif %}
  4. Si tu proveedor pide verificar la dirección de reenvío, confirma el código que enviaremos a esa bandeja, y guarda la regla.

El bloque de remitentes ya cubre todos los bancos soportados ({{ bank_senders | map(attribute='bank') | join(', ') }}). ¿Tu banco no aparece? Abre una notificación que hayas recibido, copia la dirección del remitente y agrégala al bloque con OR.
